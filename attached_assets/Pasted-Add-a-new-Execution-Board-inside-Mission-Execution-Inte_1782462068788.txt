Add a new **Execution Board** inside Mission / Execution Intelligence.

Do not remove the existing Mission Timeline or Execution Details.

The new tab should be a Jira-style Kanban board representing every task executed during the mission.

Columns:

• Backlog
• Planned
• In Progress
• Waiting for Tool
• Waiting for Human Approval
• Completed
• Blocked
• Failed

Each card represents one agent task.

Example mission:
Purchase 1T A36 Structural Steel.

Cards should include realistic tasks such as:

• Parse procurement request
• Validate material specification
• Retrieve historical purchases
• Search approved suppliers
• Retrieve ERP pricing
• Request supplier quotations
• Compare vendors
• Risk assessment
• Compliance validation
• Budget validation
• Human approval
• Generate purchase order
• Submit ERP order
• Notify stakeholders
• Archive execution logs

Each card displays:

• Task ID
• Agent responsible
• Current status
• Priority
• Confidence
• Start time
• Duration
• Tokens consumed
• Cost
• Tool/API used
• Dependencies
• Retry count
• Business impact

Cards should use enterprise colors for status.

Clicking any card opens a Task Detail drawer showing:

• Full objective
• Assigned agent
• Parent mission
• Timeline
• Prompt summary
• Reasoning summary
• Knowledge retrieved
• Memory accessed
• Tool calls
• MCP servers used
• API requests
• Documents consulted
• Decision taken
• Output generated
• Validation results
• Cost
• Token breakdown
• Latency
• Logs
• Related downstream tasks

Support:

• drag-and-drop (visual only)
• search
• filters
• agent filter
• status filter
• department filter
• priority filter
• sort
• grouping
• collapse/expand columns

Display live badges:

Completed
Running
Waiting
Blocked
Failed

The board should remain synchronized with the Mission Timeline and Execution Replay so selecting a task highlights the corresponding execution step.

Populate with realistic manufacturing procurement data consistent with the rest of the mission.

Follow the existing Onyx design language.
