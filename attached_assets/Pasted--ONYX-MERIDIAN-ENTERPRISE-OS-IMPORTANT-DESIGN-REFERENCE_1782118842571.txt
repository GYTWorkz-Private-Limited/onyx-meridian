# ONYX MERIDIAN ENTERPRISE OS

## IMPORTANT - DESIGN REFERENCE FIRST

Before generating any UI, analyze all uploaded screenshots.

The uploaded screenshots belong to the existing Onyx ecosystem.

Treat those screenshots as the PRIMARY design reference.

Do NOT redesign Onyx.

Do NOT create a new visual identity.

The goal is to extend the existing Onyx platform into an AI-Native Enterprise Operating System.

Users familiar with Onyx should immediately recognize:

* Typography
* Navigation
* Card hierarchy
* KPI widgets
* Dashboard layouts
* Information density
* Executive reporting style
* Analytics patterns

Maintain approximately:

90% Onyx visual language
10% new AI-native functionality

The result should feel like:

"Onyx Enterprise OS"

and not:

"A completely different AI platform."

---

* Existing Onyx dashboard patterns

# PRODUCT VISION

Build a prototype called:

ONYX MERIDIAN ENTERPRISE OS

Purpose:

Demonstrate how enterprises evolve from fragmented AI initiatives into AI-native operating models powered by:

* Enterprise Intelligence
* Governed Execution
* Autonomous Business Units
* AI Workforce Orchestration
* Continuous Learning
* Business Outcomes

This is NOT:

* A chatbot
* An agent marketplace
* A prompt playground

This IS:

An AI-Native Enterprise Operating System.

The objective is not to demonstrate individual agents.

The objective is to demonstrate how intelligence becomes an enterprise operating capability.
