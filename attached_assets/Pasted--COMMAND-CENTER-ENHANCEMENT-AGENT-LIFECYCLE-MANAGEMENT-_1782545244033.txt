## COMMAND CENTER ENHANCEMENT — AGENT LIFECYCLE MANAGEMENT

The current **Command Center** only displays operational metrics. Extend it into an **Enterprise Workforce Management Console**, allowing enterprise administrators to manage the complete lifecycle of every AI employee.

Do **not** redesign the existing page. Extend it while maintaining the current visual style.

Everything remains **frontend-only** using predefined static demo data.

---

# New Section

## Workforce Management

Place this section directly below the existing KPI cards.

Display every agent as an expandable workforce card.

Each card should show:

* Agent Name
* Agent ID
* Current Role
* Department
* ABU
* Current Rank / Tier
* Status
* Current Model
* Performance Score
* Trust Score
* Health
* Experience Level
* Last Evaluation
* Current Supervisor
* Total Missions Completed

---

# Lifecycle Actions

Every agent card should contain a dedicated **Lifecycle Actions** panel.

Buttons:

* Promote
* Demote
* Rollback
* Suspend
* Resume
* Fire Agent
* Clone Agent
* Transfer Department
* Transfer ABU
* Reset Learning
* Queue Retraining

Each action opens a professional modal instead of executing immediately.
